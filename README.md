# katestrudwick.com

Kate Strudwick's portfolio. Plain HTML, CSS and JavaScript, hosted on GitHub Pages.

## Swapping the homepage objects
The eight draggable objects are `assets/objects/object-1.webp` to `object-8.webp`. They land in a slightly different spot on every visit.
Replace a file with your own cut-out (a WebP or PNG with a transparent background, about 1000px on its longest side; if you use a PNG, change the file ending in index.html too)
and keep the same file name. To change what each one is called for screen readers, edit its `alt` text in `index.html`.

## Adding or changing project images
Each project has a folder in `assets/img/`. Gallery images are numbered `01.jpg`, `02.jpg`…
and are listed in that project's `index.html` (for example `runmix/index.html`).
