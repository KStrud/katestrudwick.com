Memory Chip

An indestructible data chip made from cremation ashes.

Back
Self-initiated, 2021

Bringing cremation ashes and an indestructible memory chip together to challenge the idea of mortality.

Graveyards are overcrowded, so more people are cremated and fewer permanent memorials remain. Digital records don’t last either: they become unreadable as technology moves on. How could we be remembered forever?

Research into death rituals and emerging data storage revealed an unexpected overlap. The challenge was designing an object that blends tradition and technology sensitively, then using it to imagine new rituals around death.

Ashes are mostly carbon, which heat and pressure can turn into silica. Hitachi has developed a near-indestructible silica chip that stores data as binary dots, readable by any computer from any era. Memory Chip proposes making these chips from a person’s ashes.
